What is this tab?

This tab shows six live numbers pulled from VictoriaMetrics — the metrics database that runs inside Docker. Every Django request, every ranking batch, every embedding job, and every Celery task automatically reports timing and count data to VictoriaMetrics every 15 seconds.

  • Request Rate — how busy the Django API is right now.
  • API Latency p95 — 95 out of 100 requests finish faster than this. Above 2 seconds triggers an alert.
  • Error Rate — server errors per second. Should be near zero. Above 1% triggers an alert.
  • Ranking Latency p95 — how long the Rust ranking engine takes to score one batch. Above 5 seconds triggers an alert.
  • DB Connections — active Postgres connections. Above 80 triggers an alert (max is 100).
  • Embedding Queue — content items waiting to be embedded. Above 500 triggers an alert.

Click App Health Dashboard to open Grafana for full time-series charts. Click Open VictoriaMetrics to run custom PromQL queries.
